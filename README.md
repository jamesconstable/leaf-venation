> Adam Runions, Martin Fuhrer, Brendan Lane, Pavol Federl, Anne-Gaëlle Rolland-Lagan and Przemyslaw Prusinkiewicz. 2005. *Modeling and visualization of leaf venation patterns.* ACM Transactions on Graphics 24(3), 702–711. https://doi.org/10.1145/1073204.1073251
